# ReadingNotes

个人论文精读笔记库。每篇论文一个 Markdown 文件,固定结构:

- 中文精读:解决了什么问题 / 新意在哪里 / idea 具体落在哪里 / 最大难点在哪里 / 是否能连 GitHub 复现
  - 关键概念第一次出现时,中文后面用英文括号注释(方便之后用英文讲解/组会汇报)
- 英文一目了然总结:一张大尺寸结构化 SVG 海报(问题/新意/架构图/难点/证据/代码可用性)+ 一张表格备份
